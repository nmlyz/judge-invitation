judge-invitation draws one picture of a letter inviting an AI judge to visit the writer's house. The letter is written by the armchair itself: forty years of sitters, cushions broken in but never broken, the whole garden visible from its corner, roast chicken ten steps away in the kitchen — and a footstool that insists on coming too.

## Run it

```sh
python3 main.py
```

It writes the letter to `/output/entry.png` (or `$MAKEFUN_OUTPUT_DIR/entry.png`): a 1024×1024 PNG, under 1 MiB. No network access needed; the same image, byte for byte, on every run. Everything is drawn with code — a hand-made 5×7 bitmap font, flat ink shapes and one small armchair illustration — using only the Python standard library.
